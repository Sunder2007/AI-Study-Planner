# AI Study Planner

AI Study Planner is a web-based application developed using PHP and MySQL.

## Features

* Student Registration & Login
* Subject Management
* Study Planner
* Progress Tracking
* Exam Management

## Technologies Used

* PHP
* MySQL
* Bootstrap
* XAMPP

## Installation

1. Import `study_planner.sql` into phpMyAdmin.
2. Copy project folder into `htdocs`.
3. Start Apache and MySQL from XAMPP.
4. Open `http://localhost/ai-study-planner`.
